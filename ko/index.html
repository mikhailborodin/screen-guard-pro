자주 묻는 질문 (FAQ)

Screen Privacy Blur는 Zoom, Microsoft Teams, OBS 데스크톱 앱과도 작동하나요?

네, 해당 앱에서 보호된 Chrome 탭, 브라우저 창 또는 전체 화면을 캡처할 때 그대로 작동합니다. 블러와 데이터 대체가 Chrome 내부에서 렌더링되므로 공유된 화면에도 보호된 뷰가 표시됩니다. 다른 네이티브 앱 창은 macOS 앱의 수동 오버레이를 사용하세요.

Smart Auto-Blur와 Auto-Replace의 차이점은 무엇인가요?

Smart Auto-Blur는 감지된 이메일, 전화번호, 키 등을 반투명 유리 효과로 가려줍니다. Auto-Replace는 민감한 텍스트를 사실적인 가상 데이터로 바꾸어 데모 중에도 UI가 자연스럽게 읽히도록 해줍니다. 두 기능 모두 Pro 기능이며, 수동 블러는 무료입니다.

페이지 데이터가 브라우저 밖으로 나가지 않는다는 것을 보안팀에서 어떻게 검증할 수 있나요?

감지 및 대체는 Manifest V3 확장 프로그램 내에서 로컬로 실행됩니다. Chrome DevTools → Network 탭을 열고 보호 기능을 토글하여 트래픽을 확인해 보세요. 보호 엔진은 페이지 콘텐츠를 외부로 업로드하지 않습니다. 권한 페이지도 함께 확인해 보세요.

Loom의 내장 블러 기능과는 어떻게 다른가요?

Loom은 Chrome 확장 프로그램 내 블러 기능을 유료 Business 및 Enterprise 요금제로 제한합니다. Screen Privacy Blur는 Zoom, Meet, Teams, Loom, OBS로 공유하기 전에 원본 브라우저 페이지를 보호하며 무료 수동 블러, 저장된 레이아웃, 로컬 마스킹 및 데이터 대체를 제공합니다.

Auto-Replace는 실제 운영 CRM 및 폼에서 안전한가요?

Auto-Replace는 프레젠테이션을 위해 로컬 브라우저 화면만 변경하며 백엔드 데이터베이스를 업데이트하지 않습니다. 다만 폼을 제출하면 현재 입력된 값이 전송될 수 있으므로 데모 대체가 활성화된 동안에는 폼 저장이나 제출을 피하세요.
