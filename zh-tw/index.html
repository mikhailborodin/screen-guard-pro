常見問題 (FAQ)

Screen Privacy Blur 支援 Zoom、Microsoft Teams 或 OBS 桌面版應用程式嗎？

支援！當這些桌面軟體擷取您受保護的 Chrome 分頁、瀏覽器視窗或整個螢幕時，由於模糊與替換是在 Chrome 內部渲染，分享出去的畫面即包含保護效果。若需保護其他原生桌面視窗，請使用我們的 macOS 應用程式。

Smart Auto-Blur 和 Auto-Replace 有什麼不同？

Smart Auto-Blur 會以可自訂的霧面玻璃效果遮蓋偵測到的信箱、電話與金鑰；Auto-Replace 則是將敏感文字替換為逼真的模擬資料，讓 UI 在簡報時保持自然易讀。兩者皆為 Pro 功能，手動模糊則完全免費。

我們的資安團隊如何驗證沒有任何頁面資料離開瀏覽器？

偵測與替換皆在 Manifest V3 擴充功能內本機執行。您可以開啟 Chrome DevTools → Network 分頁並切換保護狀態來檢查流量：保護引擎不會上傳任何頁面內容。也歡迎參考我們的權限說明頁面。

這與 Loom 內建的模糊功能相比如何？

Loom 將其 Chrome 擴充功能內的模糊工具限制於付費的 Business 與 Enterprise 方案。Screen Privacy Blur 則在分享至 Zoom、Meet、Teams、Loom 或 OBS 前直接保護來源網頁，並包含免費手動模糊、儲存配置，以及本機自動遮罩與資料替換。

Auto-Replace 對正式環境的 CRM 和表單安全嗎？

Auto-Replace 僅改變本機瀏覽器的簡報顯示畫面，不會更新您的後端資料庫。但由於送出網頁表單可能會傳送目前顯示的欄位值，建議在唯讀展示流程中使用，並避免在啟用替換時儲存或送出表單。
